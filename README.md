# ✊ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors Game** built using HTML, CSS, and JavaScript. Play against the computer, make your choice, and see who wins!

## 🎮 About the Project

Rock Paper Scissors is a classic game in which the player competes against the computer by choosing one of three options: Rock, Paper, or Scissors.

This project demonstrates the use of JavaScript for game logic, HTML for structure, and CSS for styling.

## ✨ Features

* 🎯 Play against the computer.
* ✊ Choose Rock, Paper, or Scissors.
* 🤖 Computer generates its own choice.
* 🏆 Determines the winner based on game rules.
* 🎨 Simple and interactive user interface.
* ⚡ Instant results after each selection.

## 🛠️ Technologies Used

* **HTML5** — Structures the game interface.
* **CSS3** — Styles the game and its elements.
* **JavaScript** — Implements game logic and determines the winner.

## 📜 Game Rules

| Player's Choice | Computer's Choice | Result      |
| --------------- | ----------------- | ----------- |
| Rock            | Scissors          | Player Wins |
| Paper           | Rock              | Player Wins |
| Scissors        | Paper             | Player Wins |
| Same Choice     | Same Choice       | Draw        |

**Remember:**

* Rock beats Scissors.
* Scissors beats Paper.
* Paper beats Rock.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Archanachaurasiya30/Rock-Paper-Scissor-game-HTML-CSS-JAVASCRIPT-.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Choose Rock, Paper, or Scissors and enjoy the game!

No additional installation is required.
